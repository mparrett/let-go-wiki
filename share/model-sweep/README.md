# Model sweep — shared copy

A snapshot for sharing, dropped on a branch of this fork. **Not wiki content**,
and not meant to merge: it sits outside the content directories, so
`check_wiki.py` ignores it.

- **[`comparison.md`](comparison.md)** — the whole comparison as markdown,
  including every generated page in a collapsible block. **Renders right here
  on GitHub**, no renderer needed. Start here.
- **[`comparison.html`](comparison.html)** — interactive comparison of nine
  models asked to document one commit. GitHub shows HTML as source, so open it
  through a renderer:
  <https://raw.githack.com/mparrett/let-go-wiki/share/model-sweep-2026-09-10/share/model-sweep/comparison.html>
- **[`story-results.md`](story-results.md)** — the written results. Renders
  natively here on GitHub.

Both are self-contained: no network calls, no build step, no credentials. Every
figure in them comes from runs against public repositories.

The full trial record these were cut from lives elsewhere and is not published.
